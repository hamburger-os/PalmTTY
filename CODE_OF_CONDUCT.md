# Code of Conduct / 社区行为准则

PalmTTY aims to be a technically rigorous, welcoming open-source project. Participation in the repository, issue tracker, pull requests, reviews and project discussions is expected to follow this code.

## Expected behavior

- Be respectful, specific and constructive.
- Critique ideas, code and trade-offs rather than people.
- Assume good intent while still requiring evidence for technical claims.
- Make security and privacy concerns explicit without sensationalizing them.
- Respect different experience levels, languages, backgrounds and accessibility needs.
- Keep discussions relevant to the project and move repeated or off-topic debate elsewhere.

## Unacceptable behavior

Harassment, threats, discriminatory language, sexualized attention, deliberate intimidation, doxxing, publishing private credentials or personal data, sustained disruption, or knowingly unsafe advice presented as project guidance are not acceptable.

Security vulnerabilities must not be weaponized in public project spaces. Follow [SECURITY.md](SECURITY.md).

## Moderation

Maintainers may edit, hide, lock or remove content; close or limit participation in threads; or restrict participation when necessary to protect contributors or the project. Moderation decisions should be proportionate, documented when practical, and focused on behavior rather than identity.

If a conduct concern also involves a security or privacy risk, use GitHub private vulnerability reporting when available. For other conduct concerns, contact the repository maintainer through the private contact method exposed on the maintainer's GitHub profile rather than escalating the matter publicly.

## Scope

This code applies to official PalmTTY project spaces and to situations where a participant is representing PalmTTY in a project capacity.

By participating, contributors agree to follow this code.
