# Support / 获取帮助

PalmTTY is currently alpha software.

## Before asking for help

1. Read the [README](README.md) and [community getting-started guide](docs/community/getting-started.md).
2. Check the [security guide](docs/community/security.md) before changing network exposure.
3. Search existing Issues.
4. Run `pnpm check` if the problem is a development/build failure.

## Where to ask

- **Confirmed bug:** use the Bug Report issue form.
- **Feature or design request:** use the Feature Request issue form.
- **Setup or usage question:** use the Question / Support issue form. If GitHub Discussions is enabled later, general support should move there.
- **Security vulnerability:** do **not** file a public issue; follow [SECURITY.md](SECURITY.md).

## Include enough context

Useful reports include the Windows version, PowerShell version, Node.js version, browser/device, deployment path (loopback/private network/reverse proxy), relevant configuration with secrets removed, and minimal reproduction steps.

Never paste access tokens, cookies, terminal transcripts containing secrets, SSH keys, private repository URLs, or unredacted environment variables.
